
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo da Forca em Python, praticando manipulação de strings, loops, condicionais, seleção aleatória e entrada de dados do usuário. Os jogadores adivinham letras para revelar uma palavra oculta antes de esgotarem as tentativas.

## 📝 Tarefas

### 🛠️ Preparar o Jogo

#### Descrição
Configure o jogo escolhendo aleatoriamente uma palavra secreta de uma lista predefinida e inicializando as variáveis que controlam o estado da partida.

#### Requisitos
O programa concluído deve:

- Selecionar a palavra secreta aleatoriamente de uma lista predefinida
- Inicializar as letras já palpitadas, o número de erros e o máximo de erros permitidos


### 🛠️ Implementar o Loop Principal

#### Descrição
Crie o loop que exibe o progresso da palavra, recebe os palpites do jogador e atualiza o estado do jogo a cada rodada.

#### Requisitos
O programa concluído deve:

- Aceitar palpites de letras e mostrar o progresso atual (formato `_ _ _`)
- Rastrear e exibir as tentativas incorretas restantes
- Encerrar o loop quando a palavra for adivinhada ou as tentativas esgotarem


### 🛠️ Exibir o Resultado Final

#### Descrição
Ao final da partida, informe ao jogador se ele venceu ou perdeu.

#### Requisitos
O programa concluído deve:

- Exibir uma mensagem de vitória quando a palavra for adivinhada
- Exibir uma mensagem de derrota, revelando a palavra secreta, quando as tentativas esgotarem
